# Hyundai Elantra 2018 Maintenance Guide

This is a WDD231 final individual website project.

## Included requirements

- Three required pages: index.html, maintenance.html, contact.html
- Responsive navigation with a hamburger menu
- Responsive layout with no CSS framework
- Local JSON file with 15 maintenance items
- Fetch API with async/await and try...catch
- Dynamic content generation showing at least four values per item
- Modal dialog for item details
- Local storage for the preferred category filter
- Array methods, template literals, DOM manipulation, and event handling
- HTML form with a form-action page displaying submitted data
- Favicon, meta descriptions, author meta, and Open Graph tags
- Optimized SVG images with alt text and lazy loading where appropriate

## Before final submission

Replace the footer Video Demo link in each HTML file with your real public YouTube, Loom, or equivalent video link. Upload the final folder to your wdd231 GitHub repository and update the Final link on your course home page.
